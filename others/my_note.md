

## 一、二节 分点

### 草稿

- 研究目的草稿
    - 深入研究相关技术
    - 攻克"Agent大脑"、"环境认知服务"、"具身模型等机器人技能的应用与优化"三个问题
    - 形成可扩展的机器人分层架构
    - 整体方案设计的实验评估
    - 提升团队成员技术认知水平与工程实践能力
- 研究内容草稿
    - "Agent层"的事件驱动主程序与现代agent引擎的相关问题
    - 环境认知服务系统(内部难度：概率性物体位置推断与概率性物体实例关联 > 几何SLAM > 房间区域语义标记)
    - "技能专家"层的调度器与封装方法
    - 各层级分布式问题与通信协议更整系统协同问题研究
    - 软硬件支撑
    - Sim2Real+实验评估

### 定稿

- 研究目的
  - 探索各种相关机器人技术的适用性与应用方法
  - 研究Agent大脑使用环境认知服务与"技能专家"的协同工作问题
  - 构建具有一定通用性的可扩展机器人分层架构
  - 实验评价整体方案的表现与效果
  - 提升团队科研创新与工程实践能力
- 研究内容
  - Agent 层事件驱动主程序搭建与引擎集成优化
  - 统一环境认知服务及其概率性实例关联与位置推断的研究实现
  - "技能专家"封装与调度方法研究及模型应用调优
  - 跨层级分布式通信与系统协同机制
  - 机器人软硬件支撑平台搭建与适配
  - 仿真到现实的迁移与项目实验评估

## 阶段

> 每个阶段：什么环境 --> 什么硬件和技术栈 --> 什么任务 --> 什么行为 --> 什么研究与评估

- **首期：受控条件下的寻物取回与体系验证**
    - **环境**
        - 地形
            - 受控室内家居环境，房间、区域用途先由用户设置。
            - 物品先放在简单、显眼、便于观测与接近的位置，不固定目标坐标和导航路径。
        - 物体
            - 使用经调优、测试确定的有限优质物品集合，同时采用开放词汇技术；小木块是已有抓取验证的起点。
            - 物品放在简单位置
            - > 中期可将物体放在地面，降低空间感知与操作难度。
    - **系统与平台**
        - 硬件
            - 集成差速底盘与单轴6自由度机械臂，前期停车后操作，定位与环境观测持续运行。
            - 传感器配置结合实际条件落实，深度相机仍属拟议选择，大概率至少有低价二手深度相机。
            - > 中期可以采用2D激光雷达，配合物体放置在地面，进一步降低难度和不依赖三维的昂贵建图硬件，但是验证整个技术栈应该是够了。
        - 软件方案
            - 先采用主Agent方案，按需要在扩展阶段探索子Agent分工，首期实现 SKILL 能力说明、技能调用与组合、上下文与记忆、失败恢复及持续状态维护。
            - "技能专家"优先优化 SmolVLA，搭建技能服务、统一环境认知与事件驱动 Agent 层。
    - **任务：寻物取回**
        - 用户提出目标 → 查询环境 → 导航与搜索 → 抓取入篮 → 返回用户位置 → 反馈结果、更新状态。
        - 首期通过 GUI 软件、命令行等方式发送指令即可，不要求实时语音交流。
        - 首期应能够返回用户所在位置。
        - > 中期可将物品送至指定区域，不要求追踪用户。
        - Agent 根据能力和反馈选择搜索方法，并应对补充要求、目标未找到、抓取失败等情况。
    - **研究评价**
        - 技能调用质量、Agent 决策应对、事件驱动运行健康、环境估计、整机表现及改善效果。
        - 首期内部再分为模块验证、初步贯通、可重复闭环与实验改进。

- **扩展：能力接入、服务拓展与应用条件演进**
    - 环境
        - **地形与空间**
            - 扩展至更多房间、功能区域和更复杂家庭环境；物品放在更任意的位置，结合感知、可达性和操作条件验证搜索与任务组织。
            - 随感知与操作条件改善，研究超出早期地面放置条件的任务；实际支持面、高度与可达范围由设备和测试确定。
            - 条件成熟后探索非家居场景中的移动操作。
        - **物体**
            - 丰富物品类别和实例，在首期已采用开放词汇技术的基础上，探索更多未预设目标的表示、关联、位置与状态维护，逐步减轻对预先列举物品集合的依赖。
            - 物品放在更复杂位置
            - 分别检验感知覆盖与操作能力，结合数据、调优和测试确定实际可用范围。
            - 同类实例与动态更新在首期已经研究，扩展时考察范围、复杂度及泛化，不将其误列为扩展阶段才有的功能。
    - 系统与平台
        - **硬件方案**
            - 按任务需要研究底盘、机械臂、传感器和计算设备升级及适配，保留上层接口与任务组织的复用。
            - 候选包括深度相机、3D雷达、多相机、双臂和升降主体；若深度相机已在首期配备，扩展研究其增配或用途拓展，不重复视为首次接入。
            - 重新核对标定、视野、可达空间、控制条件和能力边界。
        - **软件方案**
            - **技能接入与替换**：接入更多导航、视觉、抓取、放置、规划、具身模型和复合能力，比较不同实现的适配、替换与复用。
            - **模型应用优化**：按需要比较其他VLA、WAM或策略方案；开展多任务调优并关注旧能力保持、灾难性遗忘与实际能力范围。
            - **新增能力利用与复杂任务表现**：沿用首期的能力说明、调用组合、上下文、记忆、失败恢复和状态维护机制，检验 Agent 能否利用新增技能支持新服务，分析更长流程与更多能力组合带来的瓶颈，并据此改进；必要时探索其他 Agent 分担部分工作。
            - **环境认知**：扩充物体与空间信息，按需要探索自动识别或推测区域用途，保留用户设置与修订入口。
            - **移动操作协同**：探索由相应技能接管底盘并协同机械臂控制，研究控制权交接与资源约束，同时保持定位与环境认知运行。
            - **部署适配**：随模型与平台变化调整计算分配和分布部署，检验接口、事件与状态机制的复用及运行代价。
    - 任务与服务
        - **新服务类别**
            - 垃圾发现与处理、拖鞋归位、物品归位、整理和收纳等为已有候选，具体按技能和平台条件选择。
        - **任务复杂度**
            - 探索多物品、更长流程及更多技能参与的任务组合，分析协调、恢复与持续运行。
            - 首期已具有多技能协作和变化响应；扩展关注新增能力及更复杂条件，不把基本协作和改指令响应推迟到此阶段。
        - **用户移动与交付**
            - 探索跟踪用户移动，更新交付目标并调整返回或交付行动。
        - **任务来源**
            - 除响应用户指令外，探索自主发现服务需要，例如发现拖鞋需要摆放整齐；具体触发、确认和执行机制尚待研究。
    - 研究评价
        - **接入、替换与复用代价**：记录执行适配、数据调优、接口说明和上层程序改动，判断哪些机制可以复用。
        - **Agent对新增能力的利用**：分析能力理解、选择、参数、组合和边界判断，区分新增能力本身不可用与Agent不会用、误用。
        - **服务范围及复杂任务效果**：记录实际新增服务、任务结果、协调代价与新增失败模式，区分扩大物品范围、扩大区域与新增任务类别所支持的结论。
        - **原有能力保持与稳定性**：开展旧任务回归，分析模型调优后的遗忘、资源及控制冲突、新模块对持续运行的影响。
        - **平台与环境适配**：记录重新标定、调优及部署工作，分析上层复用与适配后的效果。
