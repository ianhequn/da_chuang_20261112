# 门槛数值与依据（申报书各项要求的来源对照）

> 何时阅读：需要判断某个「硬规则」是否成立、或用户问「这个要求是谁规定的」时。
> 本文件的作用是**防止无依据的数值被当成规范执行**。

## 0. 为什么需要这份文件

本 skill 的早期版本把一批数值写成「硬规则」（总字数、周期、文献数量、英文占比、
政策条数、创新点字数、效益指标数）。2026-11 对标真实评审依据时发现：
**这些数值不能当成通用要求；学校标准和国家平均资助口径均须区分适用范围。**

- 「英文文献 ≥60%」←→ 部分高校形式审查标准要求「英文文献**不超过** 50%」
- 「国家级经费 1~2 万」←→ 教高函〔2019〕13 号要求「平均**不低于** 2 万元/项」

因此本文件把所有门槛分成三类，并要求 skill 在引用时标明类别。

## 1. 国家规定（不可协商，有文号可查）

| 事项 | 规定 | 出处 |
|------|------|------|
| 平均资助标准（国家级创新训练/创业训练） | 平均**不低于 2 万元/项**，高校根据学科专业特点确定项目额度 | [教高函〔2019〕13 号](https://www.gov.cn/zhengce/zhengceku/2019-07/10/content_5456105.htm) 第九条（六） |
| 平均资助标准（国家级创业实践） | 平均**不低于 10 万元/项**，高校确定具体项目额度 | 同上 |
| 申报基本条件 | 选题有学术价值/理论意义/现实意义；有创新性；论证充分、难度适中；团队为全日制本科在读、结构合理、每人每学年原则上只参与一个项目；导师学术造诣较高 | 同上 第九条（一）~（五） |
| 项目分类 | 创新训练 / 创业训练 / 创业实践三类，定义见原文 | 同上 第四条 |
| 结题验收权责 | **由所在学校组织**，学校报省级备案，省级报教育部 | 同上 第十八条 |
| 重点支持领域 | 教育部制定重点资助领域项目指南 | 同上 第八条 |

**注意：这是平均资助标准，不是每个项目的申请下限，也不代表申请经费等于最终资助。单项额度以本校当年通知为准，不得据此要求学生把预算补到 2 万或 10 万。该办法没有规定统一字数、页数、周期或文献数量。**

## 2. 高校形式审查标准（有出处，但**校际差异大，须以本校文件为准**）

以下数值来自山东理工大学《大学生创新训练项目申报书形式审查标准》
（[原文 PDF](https://bs.sdut.edu.cn/_upload/article/files/7c/1d/9df4f9214b22b4ee5c8f454d114b/5958835d-7aba-483d-a213-fc1b134d40ad.pdf)），
可作为「一份真实存在的形式审查标准」参考，**不代表全国统一要求**。

| 审查点 | 撰写建议 | 一票否决项（原文） |
|--------|----------|--------------------|
| 项目题目 | 聚焦；字数适中 | 明显超出本科生能力范围；与内容无关 |
| 项目简介 | 简述背景、指明现有技术问题；简要说明内容与意义；建议分两段 | 无项目背景；**项目内容在此部分详细阐述** |
| 研究目的 | 简明说明为什么研究、解决什么问题 | 与内容不相关；**少于 400 字或超过 1000 字** |
| 研究内容 | **3 个为宜**；每条简短一段 | **超过 5 个**；**少于 2 个**；不相关叙述/图表过多；缺失 |
| 国内外研究现状 | 有文献标注；涵盖国内与国外；有综合评价并与创新点对应 | 无文献标注；只有国内或国外；无综合评价 |
| 参考文献 | 格式正确；**近五年占比不少于 80%**；**英文文献不超过 50%** | 没有参考文献；**只有中文或只有英文** |
| 创新点 | **3 条为宜，每条不超过 3 行**；高度凝练 | 没有明确指出创新点 |
| 技术路线 | 有技术路线图并详细阐述；**原创绘制** | 没有技术路线图；复制粘贴已有资料 |
| 拟解决关键问题 | 高度凝练；**条目数与研究内容、创新点对应** | 与创新点重复 |
| 预期成果 | 量化、可考核；**至少 3 项指标，必须含论文发表或专利申请**；明确数量 | 无论文发表或无专利申请 |
| 项目进度安排 | **分 4 个阶段**；每阶段有具体研究内容；**每阶段有考核指标** | 无进度安排；无具体内容 |
| 已有基础 | 体现**学生**的研究基础（弱化课题组成果）；说明实验室条件 | 研究基础部分缺项 |
| 经费预算 | **1 万至 2 万之间**；分配合理 | **低于 5000 元**；**高于 30000 元** |
| 指导教师意见 | 本人手写；与项目相关；2 行及以上 | 没有意见；没有签名 |
| 排版 | 图清晰；表规范；标注正确；格式一致 | 图片模糊/有水印/超链接；版面大空白；图表与标注分页；段落格式不一致；公式图片粘贴 |

## 3. 本 skill 的默认值（无官方依据，属工程约定，须可被用户模板覆盖）

以下数值是本 skill 为了「不给用户一个空洞的稿子」而设的**默认目标**，
**不是评审要求**，用户提供本校模板时必须让位于模板。

| 项 | 默认值 | 理由 |
|----|--------|------|
| 正文总字数 | 6000~9000 字 | 真实申报书实测区间 7,140~15,200 字，多数在 7,000~11,000；取紧凑段 |
| 创新点 | 3 条，每条 90~150 字 | 对齐「3 条为宜、每条不超过 3 行」 |
| 研究内容 | 3~4 条，每条 ≤250 字 | 对齐「3 个为宜、>5 一票否决」 |
| 研究目的 | 600~900 字 | 落在「400~1000」区间中部 |
| 技术路线正文 | ≤200 字 + 图 | 真实稿正文仅 50~150 字，信息在图上 |
| 进度安排 | 4 阶段，每阶段含考核指标 | 对齐形式审查标准 |
| 预期成果 | 3~5 项，含论文或专利 | 对齐「至少 3 项且须含论文/专利」 |
| 经费总额 | 不设默认额度或区间；先核对本校当年通知 | 国家平均标准不能与某校单项区间取交集后推广 |
| 参考文献 | 10~30 篇，按学科调整 | 实测 0（艺术）/10（工科）/30（医学） |
| 文献语种与年份比例 | 不设默认比例；按学科选取真实相关研究 | 第 2 节只是一校示例，须确认本校当年要求后使用 |

## 4. 学科差异（同一门槛不适用所有学科）

真实申报书的文献量、名称长度、技术路线形态随学科变化，不可一刀切：

| 维度 | 工科 | 医学 | 人文/艺术 | 社科 |
|------|------|------|-----------|------|
| 参考文献 | 约 10 篇 | 约 30 篇 | 可以 0 篇 | 10~20 篇 |
| 项目名称 | 短（≤20 字） | 可长（需写清通路/靶点） | 短，可用副标题 | 中等 |
| 技术路线 | 必须有图 | 必须有图 | 可纯文字 | 可用研究框架图 |
| 核心产出 | 样机/算法/专利 | 论文/实验数据 | 作品/展演 | 调研报告/政策建议 |

**skill 遇到非工科选题时，不得要求「算法对比表」「数学公式」「≥3 张技术路线图」。**
非技术类选题的对应物是：方法/路径对比表、研究框架图、调研方案。

## 5. 使用规则

1. 引用门槛时先判断类别：国家规定 → 按其适用主体和统计口径执行；高校标准 → 须确认本校当年文件；默认值 → 可被覆盖。
2. 用户给了本校模板/通知 → **模板优先**，默认值全部让位。
3. 用户没给模板 → 用第 3 节默认值，并在交付时说明「这是紧凑默认值，请按本校模板核对页数与栏目字数」。
4. **不得把第 3 节的默认值表述为「评审要求」或「国家规定」。**
