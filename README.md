# 大创项目工作区

本目录用于规划家居移动操作机器人项目，并据此完成项目立项申报书。文件按“项目定义—研究设计—申报书正文”分工，避免重复定义和内容混杂。

## 目录结构

```text
大创/
├─ 项目说明.md                 项目定义、特色、目标与边界
├─ 架构设计.md                 系统分层、模块职责与整体运行方式
├─ 通信_胶水_草稿.md           通信、适配、事件和接口机制的技术草稿
├─ 参考项目_references.md      参考项目与资料索引
├─ 正文思路.md                 申报书的论证顺序与章节写作逻辑
├─ 立项依据.md                 项目立项申报书正文
└─ ai_note/                    阶段性讨论稿、分析稿和版本记录
```

## 文件职责

### 项目定义与系统设计

- `项目说明.md`：说明项目是什么、题目概念如何理解、项目特色是什么，以及总体目标、首期验证和范围边界。它是项目定义的主要依据。
- `架构设计.md`：说明 Agent、环境认知服务、技能服务、机器人支持层和硬件层如何组织，回答“系统如何实现和扩展”。
- `通信_胶水_草稿.md`：记录接口、通信、任务状态和事件传递等实现细节。
- `参考项目_references.md`：保存参考项目、论文和技术资料，不直接代替研究现状正文。

### 申报书文件

- `正文思路.md`：说明申报书各章节如何回答问题、如何前后衔接；不承载具体技术方案。
- `立项依据.md`：按既定七项格式编写的正式申报书正文，是前述规划材料的最终汇总表达。

## `ai_note/` 的设计文件

`ai_note/` 保存工作稿，不直接作为最终结论。后续按需要建立以下文件：

- `项目研究问题与内容分解.md`：由项目说明拆出研究问题、研究内容和非目标；
- `环境语义地图设计.md`：规定环境认知服务中空间、区域、物体实例、历史和查询更新的最小范围；
- `验证方案与评价指标.md`：规定仿真、真机、基线、指标和扩展性验证；
- `研究现状与问题分析.md`：从参考资料中提炼已有方案和本项目切入点；
- `项目年度阶段计划.md`：规定一年期阶段目标、里程碑、交付物和风险替代方案；
- `已有基础与条件保障.md`：整理硬件、软件、实验记录、团队能力和条件缺口。

## 内容流向

```text
项目说明.md
    ↓
研究问题与内容分解
    ↓
架构设计 / 环境认知服务设计 / 验证方案
    ↓
创新点、技术路线、进度安排、已有基础
    ↓
立项依据.md
```

`正文思路.md` 负责约束最后一步的写作逻辑；`参考项目_references.md` 为研究现状和技术选择提供资料依据。
