# 大创项目工作区

本目录用于规划家居移动操作机器人项目，并据此完成项目立项申报书。文件按“项目定义—研究设计—申报书正文”分工，避免重复定义和内容混杂。

## 当前项目主线

项目名称为 **Agent 驱动的可扩展具身家居机器人**。家居服务需求多样且持续变化，而支撑机器人灵活响应这些需求的通用架构、能力接入与应用方案仍较为分散，使已有能力的协同利用和新服务的扩展面临较多适配与整合工作。项目从通用机器人应用需求出发，利用现代 Agent 驱动任务组织，以技能专家承接现有能力，以统一环境认知服务支撑真实场景决策，并通过清晰接口让新技能更容易接入、调优和复用。物品寻找与取回是首个验证场景。

研究项按架构及跨层工作划分为六个板块，见 `研究问题分解.md`。申报书“研究目的”按“背景—问题—总体研究目的”展开。第一轮调研确认相关研究有直接先例；整体方案是否呈分散、相对少见，需通过限定范围的比较论证，不表述为没有相关研究。

## 文件职责

### 项目定义与系统设计

- `项目说明.md`：说明项目概况、背景与面向的问题、特色与创新、目标与边界。它是项目定义的主要依据。
- `研究问题分解.md`：按架构和跨层工作划分整个项目的研究板块，说明各项研究内容及相互关系。
- `架构设计.md`：说明 Agent、环境认知服务、技能服务、机器人支持层和硬件层如何组织，回答“系统如何实现和扩展”。
- `参考项目_references.md`：保存参考项目、论文和技术资料，不直接代替研究现状正文。

### 申报书文件

- `正文思路.md`：说明申报书各章节如何回答问题、如何前后衔接；不承载具体技术方案。
- `立项依据.md`：按既定七项格式编写的正式申报书正文，是前述规划材料的最终汇总表达。

## `ai_note/` 的设计文件

`ai_note/` 保存工作稿，不直接作为最终结论。后续按需要建立以下文件：

- `环境语义地图设计.md`：规定环境认知服务中空间、区域、物体实例、历史和查询更新的最小范围；
- `验证方案与评价指标.md`：规定仿真、真机、基线、指标和扩展性验证；
- `项目年度阶段计划.md`：规定一年期阶段目标、里程碑、交付物和风险替代方案；
- `已有基础与条件保障.md`：整理硬件、软件、实验记录、团队能力和条件缺口。

## `search/` 的调研文件

- `20261114_调研会话任务书.md`：本轮调研目标、来源要求、交付与工作边界。
- `研究现状与问题分析.md`：代表系统对比、背景判断核验与项目主张校准。
- `各研究项初步技术路线调研.md`：六个研究板块的候选路线、本地代码核查与优先验证问题。
