# Agent 猜测记录与历史问答补充调研

调研日期：2026-11-16。用途：补充“概率性物体实例位置推断与实例关联”中的 Agent 侧问题。本文沿用本项目任务书口径，聚焦 Agent 依据感知与历史形成、保存猜测，再根据可查询历史回答用户；不把范围扩成主动搜索控制。结论只基于下列核对的一手论文，不据此宣称已完成整个记忆/Agent 领域普查。

## 一、先区分所问的能力

示例：“昨天最后一次确认看到钥匙在餐桌上。其后未观察到钥匙移动；因为用户后来收拾过桌面，机器人推测钥匙可能被放进玄关收纳盒，但尚未确认。”

这里至少有四类信息，不能压成一个自然语言摘要：

| 记录类型 | 例子 | 证据地位 |
|---|---|---|
| 感知观察 | 2026-11-14 18:20，图像/检测确认某把钥匙在餐桌上 | 观察事实，但仍受检测和身份关联误差影响 |
| 用户陈述 | 用户说“我刚才收拾了桌面” | 对话事实，不自动证明钥匙被移动 |
| 动作/事件结果 | 机器人经验证把物体放入篮子 | 由动作和结果验证支撑；命令发出本身不等于成功 |
| Agent 推测 | 钥匙可能在玄关收纳盒 | 派生假设；应保留依据、生成时间和未确认状态 |

用户查询时，Agent 应能区分“最后确认看见”“后来发生/用户说过”“据此推测”和“没有足够信息”。推测被保存，不代表它因此成为事实；新证据应能更新或撤销推测，同时保留原先记录和变更理由。

## 二、直接核对的一手研究

### 1. DAAAM：时空对象历史与 Agent 查询

[论文 arXiv v1](https://arxiv.org/html/2512.00565v1)，Gorlo、Schmid、Carlone，2025-11-29；[项目页](https://mit-spark.github.io/DAAAM/)，[官方代码仓库](https://github.com/MIT-SPARK/DAAAM)。本轮逐项核对论文 §3、§4.1–4.4 和附录 B。

- 系统将视频分割片段通过图像跟踪和 3D 几何提升组织为 4D 场景图；全局 reconciliation 合并跨窗口的实体片段，并给实体追加自然语言描述及相应时间窗口，形成空间和时间上连贯的记忆。
- tool-calling Agent 可按语义检索对象、查询半径内对象、区域信息和 Agent 轨迹；检索结果含实体描述、位置和 observation timeline。论文明确是 Agent 使用持久时空记忆回答问题。
- 原始 NaVQA 有 210 个问答样本，作者指出一些空间真值记录观察视点而非对象真实位置，另有噪声和窗口错误；他们重新标注空间位置并构建 OC-NaVQA，评估 CODa 真实机器人记录序列，最长 35.8 分钟。短/中/长样本平均记忆时长为 1.2/4.4/12.3 分钟。
- 论文实验向方法提供 ground-truth poses，属于记录数据上的时空问答/任务 grounding，不等于在线家庭助理与用户的长期交互验证。所谓 CODa 上 10Hz 是 RTX 5090 配置下的几何/系统吞吐；DAM 描述推理另有批处理延迟。
- 作者说明局限包括 OOD 对象描述可能幻觉或趋向常见类别，以及动态实体的描述历史持续增长。

**对项目的意义：**“保留过去看到什么/在哪里/何时，并由 Agent 按问题取回回答”不是空白。DAAAM 存的是由感知片段跟踪/融合出的实体描述历史，不是 Agent 对未观测事实所作猜测的专门记录；论文没有给猜测状态、依据链、真假修订或“尚未确认”回答协议。

### 2. Surprise-Gated Robot Episodic Memory：选择性事件片段与历史问答

[论文 arXiv v3](https://arxiv.org/html/2606.03787v3)，Gorlo 等，2026-06-02 首发、2026-06-06 修订。本轮核对 §2–5。

- 使用 V-JEPA-2 latent 时序特征及滑动窗口预测分布的 surprise，在局部显著峰值选取 8 帧 episodic memory；记录触发时间和机器人位姿，并附加到 DAAAM 的 4D 场景图。
- 下游 Agent 可按文本、位置或观察时间检索视觉片段，回答“机器人之前经历了什么”一类时空问题。
- OC-NaVQA 使用 7 段 CODa 机器人记录序列。作者报告 question accuracy 0.796，对比 DAAAM 0.711；位置误差 36.57m 对 41.75m，时间误差 1.510min 对 1.792min。相同记忆预算、GPT-5-mini 推理，QA 指标平均 3 个随机种子；不是在线人机问答或物体取回实验。
- 记忆约为每分钟 1.28 个片段、约占全部帧的 1.7%，代价是平均 token 使用增加 13%。作者指出惊讶后反复出现的场景会重复触发，片段仍按图文相似度检索。

**对项目的意义：**“决定哪些过去片段值得留存，并供 Agent 后续问答”已有先例；该方法并不表示物体位置/身份概率，也没有将 Agent 推测做成有明确 provenance 和后续修订状态的记忆类型。

## 三、与已有对象位置研究的关系

此前已复核的 DynaMem、OpenIN、FARM、ECROM 主要回答不同问题：DynaMem 维护最新动态空间状态和在线查询；OpenIN 以物体—家具承载关系更新支持导航搜索；FARM 以持久对象级记忆做关系 grounding；ECROM 从不均匀观察机会推断某概念长期出现倾向并形成搜索先验。它们可为“目标可能在哪里”提供地图或概率依据，但不能替代 Agent 回答用户时对来源和认识状态的表达。

因此要区分：

- **位置后验/搜索先验：**对地点候选的数值推断，通常需要明确模型、证据似然、校准和标注。
- **Agent 假设：**利用历史、用户陈述和常识提出的解释，例如“可能放进玄关盒”；它可先是定性候选，不应伪装成已校准概率。
- **用户答复：**应先检索支持材料，再组织自然语言；流畅程度或模型自报置信不构成事实依据。

Agent 可以补足规则/感知未覆盖的常识关联，但不能把常识本身当作“观察到钥匙在收纳盒”。如果地图系统有概率分数，可作为候选的一个证据源；没有校准前只应按排序/启发式分数使用。

## 四、谨慎的拟议路线

以下是基于上述对比形成的项目建议，不是已有论文已经验证的事实，也不能仅凭资料差异宣称创新：

1. 使用追加式原始记录保存观察、用户陈述和经过验证的动作结果；Agent 假设单独保存，引用其依赖的记录 ID。
2. 每条假设保留目标实体/类别、候选位置或解释、生成时间、依据、作用时间范围、确认状态和修订关系。第一版可用“未确认/部分支持/被反证/过期”等定性状态；不强行生成未经校准的概率。
3. 新观测支持或反驳假设时，追加新的证据和状态变化，不重写原始观察。身份关联不确定时保留多个候选或“无法区分”，不让 Agent 仅凭名称将相似实例合并。
4. 用户问“你最后一次确认看到钥匙在哪里？”只回答有明确观察记录支持的位置/时间。问“你觉得钥匙可能在哪？”才总结有来源的推测，并明确“这是基于……的推测，尚未确认”。证据不足时返回未知。
5. 评价关注回答的证据引用正确率、观察/用户陈述/推测混淆率、矛盾证据后的更新正确率、无依据断言率、时间/身份归属错误，以及长序列下历史检索和存储代价。

可设计三个对照：仅检索原始观察；加上 4D 实体/事件时间线；再加入独立 Agent hypothesis records。用“最后看到何处”“之后有无确认移动”“依据目前历史可能在哪”“若新记录与旧推测冲突如何回答”等问题测试。数据标注要包含可见性、观察机会、实体身份歧义以及对话/动作时间，避免只用最终取回成功率替代问答来源正确性。

## 五、调研结论与未决问题

1. **已有先例充分支持**：机器人保存跨时间对象/场景状态，Agent 从历史中检索，并回答时空问题；也已有选择性保存事件片段以改善历史 QA 的方法。
2. **目前未查到直接证据**：将 Agent 根据历史生成的猜测作为独立认识状态保存，并持续记录支持/反驳证据，用户提问时明确呈现事实、来源和未确认状态。这里只能说本轮两篇直接先例没有覆盖、而且现有报告覆盖不足；尚不能说整个研究领域没有此类工作。
3. **还需定向检索**：agentic memory、belief/provenance-aware dialogue、uncertain temporal knowledge graph、robot autobiographical memory 和带冲突修订的问答系统；逐篇确认是否包含实体机器人、物体位置事件、猜测来源与在线更新。
4. **项目表述建议**：把“概率性物体实例位置推断”与“Agent 依据记忆生成并说明猜测”作为地图/记忆与用户交互相接的两个问题；首期先验证候选保留、证据溯源和不确定回答，不承诺未经验证的概率置信或任意物体长期追踪。
