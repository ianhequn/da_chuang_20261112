# 项目分阶段基线与评价标准补充调研

核查日期：2026-11-19。只修改调研工作稿；本次没有安装基准、运行模型或声称取得评测结果。以下区分公开基准、算法基线和本项目拟议验收方案。网页可能更新，实际运行前应固定代码提交、任务版本、模型与协议。

## 一、选择结论

建议采用“分阶段验证＋同条件对照”，不要只选一个总榜单。RoboDojo 用于操作与工具执行原型，HomeRobot OVMM 对照首期移动取放流程，RobotAgentBench 用于情境推理、异常恢复和综合 Agent 任务设计；环境认知、历史回答、事件运行机制和服务扩展另设小规模标注测试。论文分数不能作为本项目验收阈值，也不能跨平台直接排名。

## 二、核查到的公开基准

### RoboDojo｜按需选用

[论文 v3，§3.1–3.3](https://arxiv.org/html/2607.04434v3) · [官方 Agent Track 协议](https://robodojo-benchmark.com/leaderboard/protocol?lang=en)

论文评测含 42 项仿真和 18 项真机任务，分别采用每项 50 个仿真回合和 10 次真机试验，区分完整成功和部分进度。仿真使用 ARX X5 双臂，真机覆盖 ARX X5、Piper 与 Piper X。仿真和真机任务未逐一配对。官方榜单另有三随机种子、隐藏布局验证及跨本体要求。Agent Track 允许通用技能和 VLA/VLM，要求冻结系统，每回合重新初始化记忆。

首期适合借鉴抓放、干扰物、遮挡和多步完成条件。只有本体与接口匹配且已有仿真基础时才考虑运行公开任务子集。跨任务历史和新增技能收益用本项目独立对照。

### RobotAgentBench｜借鉴情境测试与诊断

[原论文 v1，§2.2–2.3、§3.1 与附录 D](https://arxiv.org/html/2610.34649v1)

原文确认 90 项原子任务、18 项短程任务、8 项长程任务和 4 个开放情境。任务级区分任务发现、情境推理、操作、失败恢复和鲁棒性。情境级以检查点进度为主，并报告任务覆盖、恢复与停滞。评测使用与 AgiBot G1 对应的观测与动作接口。论文的数据生成阶段使用仿真全状态，正式比较使用相机、自身状态及按规则逐步揭示的导航地图。

优先借鉴目标选择、抓取失败恢复和目标搬动扰动。整套平台及开放家务任务留作后续候选。

### HomeRobot OVMM

一手来源：https://github.com/facebookresearch/home-robot

本轮核对官方仓库任务定义。OVMM 输入是新环境中的目标物类别指令，将物体从起始 receptacle 移动到目标 receptacle；相较纯桌面基准，它更贴近本项目的搜索、导航、抓取和放置衔接。仓库提供仿真及真实系统入口，但环境、本体、资产和依赖仍需运行前检查。

适合：首期整机流程的仿真参照。完整任务是否成功应依据全部目标与约束；阶段成功单独记录。目标类别泛化与指定历史实例寻找是不同任务；入篮后返回用户等额外环节也需要本项目自己定义。建议额外使用同一感知/技能下的固定任务流程基线，分辨收益来自 Agent 组织还是底层能力变化。

### LIBERO

一手来源：https://github.com/Lifelong-Robot-Learning/LIBERO

候选资料入口。若后续涉及策略持续训练，再复核任务套件及评测实现。适合操作模型的任务泛化、顺序学习和遗忘测试；不是移动家居服务基准。若项目只接入冻结技能而不训练策略，不应把接口扩展结果说成 LIBERO 意义的持续学习。

### BEHAVIOR

一手来源：https://behavior.stanford.edu/omnigibson/metrics.html

待按选用版本复核。候选指标将 task success score 定义为已满足目标条件比例，范围 0–1；并有时间、移动/操作努力等效率量。因此必须同时区分“部分目标进度”和“所有要求满足的完整任务成功”。适合借鉴家居目标谓词、长期操作任务以及阶段进度，但安装、资产与算力成本应在选用前单独核查，不能因为任务丰富就全量复现。

### HOTA / TrackEval

一手来源：https://github.com/JonathonLuiten/TrackEval

候选指标包括 HOTA、关联准确度和 IDF1，实际采用前核对实现版本和标注要求。适合身份关联错误分析，但连续视频轨迹指标不能直接覆盖跨天、离开视野后搬动的家庭物体记忆；必须自建相应标注序列。位置或身份分布的概率质量也要独立评估，不能以跟踪准确率替代。

## 三、按项目阶段选择基线和指标

下表是本项目拟议实验方案，不是各公开基准的官方要求。

| 阶段 | 推荐参照/基线 | 主要评价 | 要控制的条件 |
|---|---|---|---|
| 1 单项能力与接口原型 | RoboDojo 匹配任务；人工通过同一接口；同一模型直接调用 | 单技能成功率、参数有效率、误用/无效调用、规划与执行耗时、人工干预 | 相同物品、视角、工具、感知权限、重试/时限；人工只能使用约定信息 |
| 2 环境认知与历史回答 | 类别＋最近位置；加入外观/时间；确定单候选与保留歧义候选；原始记录检索与结构化历史/猜测记忆 | 错误合并/拆分、身份切换、位置区域 top-k/未知识别、更新延迟；回答的证据正确性、时间归属、事实/推测混淆 | 同一观测流、身份/位置真值、可见性和动作/对话日志；不能给待测系统真值 |
| 3 Agent 与事件运行 | 固定流程/状态机＋同样地图技能；无持久记忆/无认知服务等受控消融；RobotAgentBench 选定情境 | 目标完成、合理应对与恢复、求助、工具调用；事件遗漏/重复/迟到处理、目标变化生效时间、取消确认和停止延迟 | 相同模型、工具、初始状态和扰动；决策质量与程序调度故障分别统计 |
| 4 仿真与真机整机 | HomeRobot OVMM 流程参照；同平台固定流程；人工同接口操作诊断 | 端到端及分段成功、总耗时、搜索距离、交接失败、重试/干预、最终状态验证 | 仿真/真机分开报告；记录环境、物品、初始位置、用户位置和操作约束 |
| 5 服务扩展与回归 | 冻结首期版本；新增/替换技能前后；必要时参照 LIBERO 遗忘评价思想 | 新服务成功、旧任务保持、能力说明/适配/上层代码改动、集成调优成本、无新增技能对照 | 固定模型版本和旧测试集；新物品/参数变化、已有技能重组、新能力接入分别归类 |

阶段 2 若输出数值概率，应额外报告 Brier score/负对数似然与可靠性图；若只是排序或定性 Agent 假设，则报告候选命中、依据和确认状态，不称为校准后验。DAAAM/OC-NaVQA 等历史 QA 可沿用既有专项调研作为任务参照，但不能代替本项目的猜测来源、身份歧义与矛盾更新测试。

阶段 3 的程序测试至少包括：用户执行中改目标、迟到/重复结果、工具超时/失败、断连恢复、取消过程中又到达完成消息。事件响应时间要区分入队、被 Agent 处理、决策完成、取消被执行端接受与物理停止，避免只测一次消息注入延迟。

## 四、通用实验协议与验收阈值

1. 在测试前固定目标完成条件、允许干预、预算和停止规则；抓取、入篮、返回、用户条件与对象身份均应验真，不能以 Agent 自报成功判定。
2. 同一任务比较不同方案时，采用成对初始配置/随机种子；测试物体、场景和时间段与调参数据分开。
3. 同时报告成功次数/总次数、每任务成绩及宏平均、波动和区间；不要只给总体百分比。本项目按预实验的波动确定重复次数。
4. 样本量由预实验估计波动和所要识别的改进幅度决定，不凭空规定 80%/90% 为合格。小样本阶段以明确能力边界和失败诊断为主。
5. 底层能力/感知真值可做诊断上界，但单列为 oracle 条件；人工全视野操作也不是与机器人公平排名的默认基线。
6. 所有公开基准适配后应标作“借鉴某基准设计的项目测试”，只有严格遵守任务、版本、预算和权限才可报对应官方分数。

## 五、近期最小落地组合

优先准备四套资料：RoboDojo 中与首个机械臂技能匹配的任务；有限实例搬动/遮挡的认知标注序列及历史追问；Agent 异常与改指令场景；首期寻物取回真机重复任务。HomeRobot 和 RobotAgentBench 为整机/情境设计参照；LIBERO 与 BEHAVIOR 先作候选，不将全量复现加入一年期必需工作。此处是依据项目范围给出的取舍建议，尚未测试安装或复现可行性。

## 六、首期优先做的三组项目对照

| 对照 | 固定条件与改变量 | 首要指标 |
|---|---|---|
| 环境判断给 Agent 带来的收益 | 同一感知、Agent、技能、初始物品与干扰。比较“只查最后观测”与“可查历史证据、身份/位置候选和未知状态”。覆盖旧位置遮挡、未观测搬动、同类物体误认及用户追问 | 正确实例取回次数 / 总回合、错取次数 / 总回合、首次找到目标耗时、无依据断言率。另在同一观测回放上测身份错误和前 k 个区域命中，定位收益来源 |
| Agent 组织与恢复 | 同一平台及技能比较固定流程和 Agent，给双方相同观测与预算，在等价时点注入抓取失败、搬动或用户改指令 | 完整成功率、受扰回合的恢复率、旧目标误执行次数、干预次数。人工同接口操作用于诊断当前接口能支撑的行为 |
| 从寻物到地面整理 | 首期版本作为对照。先用旧技能跑整理，再适配新增技能跑相同整理用例。用同一批寻物测试检验回归 | 正确归位与完整整理成功率、旧任务成功率变化、实际修改的上层逻辑/技能说明/适配代码及调优工时 |

环境认知阶段还可借鉴 [DynaMem v2 §4.1–4.3](https://arxiv.org/html/2411.04999v2) 的静态记忆对照、动态物体取放与离线定位分开评价。它提供选择对照的依据。本项目在同一平台实现“最后观测”作为轻量基线，加入指定实例、历史问答与跨时证据等项目条件。

以上三组优先于复现整套公开榜单。RoboDojo 选与本体匹配的少量抓放或遮挡用例。HomeRobot 用于定义取回流程。RobotAgentBench 用于选择扰动和恢复场景。论文或榜单分数供理解测量口径，项目验收阈值由预实验确定。
