# 环境语义地图设计

整理日期：2026-11-15。本文维护环境认知服务的内部设计工作稿，承接原《架构设计_temp.md》中仍有效的内容，并按当前讨论校准。层间关系以《架构设计.md》为准，候选算法及证据见技术路线调研稿，尚未定型的方案不作为已实现功能。

## 服务范围

环境语义地图是独立的环境认知服务，连接感知观测、任务决策与技能执行。此处的环境表示不等同于具身模型中的生成式世界模型；几何建图与感知链优先复用适用组件，不以重新研究基础 SLAM 为目标。

- **几何空间**：接入适用的二维地图或三维点云、网格及定位信息，提供区域、支持面和导航目标的空间依据；表示形式结合平台及任务确定。
- **区域用途**：允许用户标记房间和区域用途。首期可用配置文件或 JSON 维护标记，自动识别属于可扩展方向，并非既定实现。
- **物体与历史**：管理类别、实例特征、位置候选、观测时间、来源及相关不确定信息，区分当前状态估计与原始观测记录。
- **联合推断**：历史实例关联与当前位置推断在同一系统中处理，共享观测和动作证据；身份、位置及长期出现倾向分别表达，歧义时允许保留候选。

## 对外服务

提供环境查询、观测提交、状态更新和历史追溯接口，供 Agent 和技能专家使用。候选位置应附时间、证据摘要及相应置信信息，便于调用方判断是否需要继续观察；不由 Agent 自由生成物体坐标。

用户侧可考虑图形化显示候选区域及置信信息，作为查询和调试辅助，暂不增加为首期必需交付。原临时稿中的“0.78”为示意数字，不是实验结果，不沿用为设计阈值或概率校准证据。
