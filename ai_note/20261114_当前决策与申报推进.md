# 当前决策与申报推进

更新日期：2026-11-14。本文记录本轮讨论后的项目主线和推进状态，供后续会话接续；具体定义以根目录维护文件为准。历史讨论仍保留其原有语境。

## 一、当前决策

- **项目名称**：Agent 驱动的可扩展具身家居机器人。
- **面向的问题**：家居服务需求多样且持续变化，而支撑机器人灵活响应这些需求的通用架构、能力接入与应用方案仍较为分散，使已有能力的协同利用和新服务的扩展面临较多适配与整合工作。
- **总体目标**：从通用机器人应用需求出发构建分层系统，利用现代 Agent 驱动任务组织，以技能专家接入和组合现有能力，以统一环境认知服务支撑真实场景决策，并通过清晰接口让新技能更容易接入、调优和复用。
- **技术主线**：从通用应用需求出发进行分层设计；利用现代 Agent 能力驱动任务组织，以技能专家承载具身模型及其他执行方案，以统一环境语义地图支撑真实需求；胶水通信和软硬件平台支撑协同，仿真到现实属于实现与验证路线。
- **首期验证**：有限物品和受控环境下的寻找、抓取入篮、返回用户。寻物是首个验证场景，整体项目面向多样任务需求与服务扩展。
- **物体语义**：在同一环境认知系统中联合维护概率性实例关联与位置推断，共享物体实例、观测历史和状态更新。
- **研究项含义**：按整个机器人项目的工作板块拆分，大体依据架构并补充跨层工作。目前形成六项草案：技能专家、环境语义地图、Agent 层、胶水通信、软硬件支撑平台、模型与整机的仿真到现实调优。
- **文档职责**：《项目说明》采用“概况—背景与面向的问题—项目特色与创新—项目目标与边界”；《正文思路》说明写作逻辑，研究目的按“背景—问题—总体研究目的”展开；申报正文保留七项格式。

## 二、写作与论证要求

让评审先理解最终机器人及其用途，再理解问题、目标、研究内容、特色和实现依据。应用问题应从需求与服务能力的关系表达，技术设计说明如何回应它。研究内容说明各板块研究什么，技术路线进一步说明怎样落实。

创新点已于2026-11-15经用户确认，采用“技能专家抽象与组织方法—统一环境认知方法—事件驱动Agent可扩展分层架构”的关系，前两项并列支撑第三项。具体标题以《项目说明.md》和《正文逻辑链条.md》为准，原“通用性、Agent驱动、语义地图”保留为总体方向，不再作为三项标题。正文说明三者如何协同，以及与近似框架的关系。技能封装用于承接现有技术生态；Sim2Real 属于技术路线和验证。相关整体方案的比较以目标、能力接入、环境状态和验证范围为依据，说明方案与接入方式较为分散的具体表现；生态集中度与成熟度需另有证据。

首期任务完成、执行条件变化后的任务调整，以及新技能经接入、适配和调优后的复用与服务扩展，分别需要相应证据。验证记录目标服务、技能适用条件、所需调优及上层改动。跨物品、跨区域复用与跨任务类别扩展应区别说明，不以一次寻物成功证明任意任务能力。
