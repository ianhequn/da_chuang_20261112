# 申报书正文大纲

> 本文件是《正文思路.md》的结构化提纲。前者记录写作思路和章节逻辑，本文件用于快速查看全文结构。

## （1）研究目的：为什么做、总体要达到什么目标

1. 技术背景：机器人、Agent、具身模型、环境语义地图和移动操作技术发展；
2. 现实问题：单项能力丰富，但面向整体应用的系统组织仍需探索；
3. 项目目标：构建融合语义地图的 Agent 驱动具身移动操作机器人可扩展通用架构；
4. 首个验证场景：家居环境中的物品寻找、抓取入篮和返回；
5. 项目价值：系统工程化落地、团队技术积累和工程实践能力提升。

## （2）研究内容：具体研究什么

1. 通用移动操作机器人分层架构；
2. 技能专家统一抽象与调用机制；
3. 面向任务决策的环境语义地图；
4. Agent 驱动的事件式长程任务编排；
5. 系统原型与仿真/真实任务闭环验证。

## （3）国内外研究现状和发展动态：别人做到哪里

1. 移动操作机器人及其系统方案；
2. 分层架构与机器人系统工程化；
3. Agent 驱动的机器人任务规划；
4. SLAM、环境语义地图与物体跟踪；
5. 具身模型与机器人操作技能；
6. 多技能组织与技能路由；
7. 对已有方案的能力边界和系统性不足进行归纳。

## （4）创新点与项目特色：我有什么不同

1. 通用性：面向整体应用的可扩展分层架构；
2. Agent 驱动：利用现代 Agent 组织多技能完成长程任务；
3. 语义地图：为 Agent 提供持续更新的真实环境状态；
4. 三者递进形成系统价值。

## （5）技术路线、拟解决的问题及预期成果：具体怎么做、交出什么

1. 用户目标；
2. Agent 理解与规划；
3. 语义地图查询；
4. 技能专家调用；
5. 导航、视觉搜索、具身抓取入篮；
6. 返回用户、事件反馈和地图更新；
7. 拟解决的问题；
8. 预期系统、实验和文档成果。

## （6）项目研究进度安排：何时完成

1. 总体方案与技术生态调研；
2. 最小接口与原型；
3. 仿真闭环；
4. 真实模块接入；
5. 复用与扩展验证；
6. 总结和成果整理。

## （7）已有基础：凭什么能做

1. 分层架构、Agent、语义地图和胶水机制设计积累；
2. 硬件和 MCU 固件基础；
3. ROS 2/Nav2 仿真与真机导航基础；
4. SmolVLA 六自由度机械臂概念验证；
5. 现有技术调研、团队能力和条件保障；
6. 尚缺条件与解决方案。
