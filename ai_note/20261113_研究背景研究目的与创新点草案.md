# 研究背景、项目切入点、研究目的与创新点草案

> 本稿用于后续扩写《立项依据.md》。其中关于国内外方案“缺少通用分层架构”的判断，仍需通过论文、官方资料和开源项目进一步核实，正式申报时应避免未经检索就表述为“国内外空白”。

## 一、研究背景与技术现状

移动操作机器人需要在真实环境中同时完成环境感知、空间定位、路径规划、移动、目标识别和物体操作。近年来，SLAM、导航系统、开放词汇视觉、对象级语义建图、机械臂运动规划、VLA 等具身模型以及 Agent 工具调用框架分别取得了较快发展，为机器人完成复杂任务提供了越来越丰富的技术基础。

现有技术生态已经能够较好地支持许多单项能力或特定任务。例如，SLAM 和导航框架可以提供几何地图与移动能力，语义感知系统可以提供物体类别和空间关系，VLA 等具身模型可以完成特定操作任务，Agent 可以进行自然语言理解、工具调用和多步骤规划。这些成果降低了构建机器人系统的门槛，也使“利用已有技术组合出可用系统”成为现实路径。

但从公开的移动操作机器人方案看，系统往往围绕某一类核心能力或某一个具身模型组织。部分商业机器人以明确的产品任务为中心，在有限物品集合、固定操作流程和受控功能范围内实现收纳、分类或清洁；部分研究和开源平台则以某一套 VLA、模仿学习策略或操作模型为主要能力来源，系统架构与该模型的输入输出和任务范围联系较紧。这类方案在特定任务上可以取得良好效果，但不同模块之间的环境状态表示、能力调用方式、任务生命周期和失败恢复机制未必具有统一的抽象。

目前尚不能仅凭已有了解断言不存在 Agent 驱动、语义地图和具身技能相结合的通用机器人架构。更稳妥的判断是：这类能力和思想可能分别存在于不同研究方向、系统框架或实验平台中，但面向移动操作机器人、将环境语义状态、现代 Agent 长程编排和可替换具身技能组织成统一工程骨架，并通过仿真到真实任务闭环进行验证的公开方案仍值得系统研究和比较。

## 二、项目切入点

本项目不把某个 VLA、视觉模型或导航框架作为系统的唯一中心，而是从整体应用技术和工程架构出发，研究如何利用现有生态形成可持续运行的移动操作机器人系统：

- 以环境语义地图组织几何空间、区域用途、物体实例候选位置、观测历史和置信度，为任务决策提供持续的环境状态；
- 以技能专家抽象导航、视觉搜索、具身抓取、运动规划等机器人能力，使不同模型、算法和设备能够通过统一接口接入；
- 以 Agent 作为任务编排中心，利用自然语言理解、工具调用、长程规划、记忆和事件响应能力，在技能结果和环境变化的推动下持续决策；
- 以胶水机制连接地图、技能、机器人支持软件和硬件，统一处理异步任务、状态转换、事件传递和仿真/真实模块替换。

家居环境是本项目的主要应用背景和首要验证场景。物品寻找与取回任务能够同时检验环境状态、候选位置推断、任务规划、移动导航、视觉搜索、具身抓取和任务结果更新。通过更换物品集合、区域和技能实现，可以检验架构是否具有基本复用能力。

## 三、研究目的

本项目旨在面向移动操作机器人在真实环境中的系统化落地需求，构建并验证一种融合环境语义地图、Agent 长程任务编排和可替换机器人技能的可扩展通用架构。

具体目的包括：

1. 建立清晰的分层系统组织方式，明确 Agent、环境语义地图、技能专家、机器人支持软件和硬件之间的职责及接口关系；
2. 建立面向任务决策的环境语义信息表示，使机器人能够利用物体历史观测和概率性位置线索安排搜索顺序；
3. 建立技能专家的统一封装和调用机制，使导航、视觉搜索和具身模型等能力能够被 Agent 组合使用并在必要时替换；
4. 建立事件驱动的长程任务执行流程，使系统能够根据技能成功、失败、超时和环境变化调整任务；
5. 通过仿真和第一代真实平台上的物品寻找、抓取入篮和返回任务，验证上述架构的可行性、协同性和基本扩展能力。

## 四、创新点与项目特色

### 1. 面向移动操作系统的 Agent—技能专家协同架构

项目将 Agent 的长程任务理解与编排能力，与 VLA 等具身模型、传统规划器和其他机器人能力统一抽象为可调用、可替换的技能专家。项目特色不在于提出新的具身模型，而在于研究不同能力如何在同一任务运行时中协同，并在技能失败或环境变化时继续推进任务。

### 2. 面向任务决策的环境语义地图组织方式

项目利用成熟几何建图和语义感知技术，组织空间、区域、物体实例候选位置、观测历史和置信度，并将其封装为 Agent 可查询和更新的环境状态服务。第一阶段采用概率性位置推断，不要求绝对准确的物体身份追踪，使语义地图能够以较低实现成本服务于真实任务搜索和决策。

### 3. 面向仿真到真实的可扩展系统验证

项目围绕统一的任务和技能接口，在轻量仿真环境与真实移动操作平台上逐步接入模块，并通过更换物品、区域或技能实现检验任务流程的复用性。该方法把“通用架构”转化为可观察的实验问题，而不只停留在概念设计层面。

### 项目特色的整体表达

项目以家居环境为主要验证场景，但关注的是移动操作机器人技术的整体组织问题。它利用现有技术生态降低单项算法研发负担，把研究重点放在跨模块的状态、接口、任务和事件协同上；同时保留接入不同具身模型、机器人技能和后续硬件平台的空间，适合作为一年期创新训练项目的系统性探索。

## 五、需要后续核实的论证事项

- 检索是否已有公开方案同时具备 Agent 长程编排、语义地图和可替换具身技能；
- 比较石头 G30 Space 探索版、Sunday 等方案时，确认其公开功能和技术描述，避免过度推断内部架构；
- 补充 Mobile ALOHA、OK-Robot、TidyBot、LeRobot 及相关论文的系统架构和任务范围；
- 依据检索结果决定使用“现有方案较少关注统一工程骨架”“相关能力分散于不同系统”还是更强的创新表述；
- 为三个创新点分别设计基线和评价指标，证明其不仅是模块堆叠。
