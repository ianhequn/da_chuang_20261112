# "层内接口封装"、"各层间服务接口协议"和"胶水层"

## 层内接口封装

- 技能层：语义地图/原子任务层
    > 面向Agent 可以封装成cli工具
- Agent层
    - 事件驱动的环境以嵌入和调用Agent引擎
    - 为Agent终端工具(bash)提供异步cli工具包
    - 可以考虑为Agent定制工具(custom tools)

## 各层连接说明草稿（胶水层）

- 移动操作机器人一般将不是由一台主机运行所有程序，一般将是分布式的。例如具身模型推理将交给推理服务器。那么，胶水层将有多种实现方式。
    - ROS2 DDS
    - ROS2 转接节点
    - tcp/udp
    - gRPC/WebSocket
    - http/https后端服务
